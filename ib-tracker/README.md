# IB Tracker

## 시스템 의도

매일 받는 IB(투자은행) 리포트에서 **검증 가능한 주장과 예측을 구조화된 데이터로 누적**하고, 시간이 지난 뒤 **IB별 적중률**과 **시장 합의 검증**을 가능하게 하는 시스템.

리포트는 휘발성 텍스트로 흘러가지만, 그 안의 정량 예측치 · 시각 · 추천 포지션 · 검증 가능 사건 · 핵심 주장은 시간이 지나야 진위가 드러난다. 이 시스템은 그 시차를 메우기 위한 개인용 판단 데이터베이스다.

## 폴더 구조

```
ib-tracker/
├── reports/raw/           # 매일 받는 원본 리포트 텍스트 저장
├── reports/processed/     # 추출 완료된 리포트 표시용
├── database/              # 누적 데이터베이스
│   ├── predictions.csv    # 정량 예측치
│   ├── views.csv          # IB별 시각
│   ├── positions.csv      # 추천 포지션
│   ├── catalysts.csv      # 검증 가능 사건
│   └── consensus.csv      # 핵심 주장 + 역베이지안 분석
├── scripts/               # 처리 스크립트
└── README.md              # 시스템 사용법
```
